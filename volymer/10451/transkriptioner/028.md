## Osäkra passager
| Rad | Bästa gissning | Varför |
|---|---|---|
| 3 | noga … [denna?] | "noga" med v-liknande n (alt. "vaga"). Sista ordet d-e + två bågar + a utan långt s → "denna", fast "dessa" passar grammatiskt till "förflyttningar" rad 4. |
| 5 | Långsamt | Tydligt "Långsamt"; oväntat i sammanhanget. |
| 7 | [bilmun/bilmor?] | Skrivet "bilm" + två–tre bågar och utdragen slutstapel; kanske förkortning (bilmotor? bilmarsch?). |
| 20 | Suna. | Efter namnet ett kort streck vid radslutet (punkt, bindestreck eller tankstreck). |
| 24 | [Koivu?] | Skrivet "Koiru/Koivu"; inte "Kavio" (inget a). |
| 27 | [Murka/Nurka?] | Versalen i handens "Vl"-form, sedan "urha" (h = k); se 027:10. |
| 28 | [motlin/moltin?] | m-o + hög ögla + kort stapel + i + n, med ett streck ovanför (t-streck?); ortnamn eller förkortning. |
| 36 | Kottila? | tt med gemensamt tvärstreck (båda läsarna); frågetecknet efter namnet står i originalet. |
